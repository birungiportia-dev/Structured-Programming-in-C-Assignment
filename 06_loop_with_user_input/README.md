Program Title: Sum and Average of a Sequence of Integers
Category: Loop with User Input

Textbook Reference :Chapter 4, Exercise 4.9

Description
Write a C program that first reads the number of integers the user wants to enter. The program then reads each integer one at a time, calculates their total sum, and determines their average.

Main Concepts Used
Variables
Integer and floating-point data types
scanf()
printf()
for loop
Accumulator variable
Average calculation
Type casting

How the Program Works
The program first asks the user how many integers they will enter. A for loop is then used to read exactly that number of integers, one at a time. Each integer is added to the running sum. After all the values have been entered, the program calculates the average by dividing the sum by the number of integers. The sum and average are then displayed.

Example Run
Input
How many integers will you enter?: 3
Enter integer 1: 56
Enter integer 2: 44
Enter integer 3: 2

Output
Sum = 102
Average = 34.00
