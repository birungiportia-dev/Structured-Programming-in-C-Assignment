Program Title: Basic Output Program
Category: Basic Output

Textbook Reference: Deitel &Deitel, C How to Program,9th Edition,Chapter 2, Exercise 2.3(e)

Description
Write a C program that displays the message "This is a C Program" on the screen.

 Main Concepts Used
- Basic structure of a C program
- `#include <stdio.h>`
- `main()` function
- `printf()` function
- Standard output

 How the Program Works
The program begins with the standard input/output library, `stdio.h`, which provides the `printf()` function. The `main()` function contains a `printf()` statement that displays the required message on the screen. The program then terminates.

Example Run
 Output
I am learning Structured Programming in C
