About the Assignment
This repository contains my Structured Programming in C assignment. It includes eight C programming exercises covering basic output, input and processing, decision statements, loops, calculations, user input, and interactive console programs.
Each exercise contains; a C source file(.c) a README file explaining the problem, concepts used, how the program works and an example run and the relevant textbook reference

Textbook used for the assignment - Deitel & Deitel, C How to Program, 9th Edition.
