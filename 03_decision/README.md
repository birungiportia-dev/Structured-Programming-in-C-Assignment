Program Title: Odd or Even
Category: Decision Statements

Textbook Reference : Deitel &Deitel, C How to Program,9th Edition,Chapter 2, Exercise 2.22

Problem Description
Write a C program that reads an integer and determines whether the number is even or odd.

Main Concepts Used
Variables
Integer data type
scanf()
printf()
if statement
else statement
Modulus operator %
Conditional expressions

How the Program Works
The program asks the user to enter an integer and stores it in a variable. It uses the modulus operator % to divide the number by 2 and check the remainder. If the remainder is 0, the number is even. Otherwise, the number is odd. The result is then displayed using printf().

Example Run
Input
Enter an integer: 17

Output
17 is odd.
