Program Title: Product of Three Integers
Category: Input, Process and Output

Textbook Reference: Chapter 2, Exercise 2.5

Problem Description
Write a C program that reads three integers from the user, calculates their product, and displays the result.

Main Concepts Used
Variables
Integer data type
scanf()
printf()
Arithmetic multiplication
User input and output

How the Program Works
The program declares variables to store three integers. It prompts the user to enter the three values and uses scanf() to read them. The program then multiplies the three integers together and stores the result. Finally, it uses printf() to display the product.

Example Run
Input
Enter three integers: 4 5 2

Output
Product: 40
